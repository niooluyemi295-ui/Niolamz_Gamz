# ✨ Niolamz Gamz

A colourful, responsive mini-game arcade built with plain HTML, CSS and JavaScript. No installation or build step required.

## Play locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser (Microsoft Edge, Chrome, Firefox or Safari).
3. Choose a game and play!

## Games
- **Heart Clicker** — tap hearts before the 15-second timer runs out.
- **Memory Match** — match all six pairs.
- **Tic-Tac-Toe** — two-player local game.
- **Cake Catcher** — catch falling treats with keyboard or pointer controls.

Coins, games played and best score are saved in the browser using localStorage.

## GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save. After GitHub finishes publishing, the site will be available at:

https://niooluyemi295-ui.github.io/Niolamz_Gamz/

## Files
- `index.html` — arcade layout
- `style.css` — responsive styling and animations
- `game.js` — game logic and saved stats
